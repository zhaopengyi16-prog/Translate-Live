# 字幕链路源码审查与修复

审查基线：`430df950701a4bfa7b6a872819aaadde2acf5df5`（`Fix continuous caption window identity replay`）。

本轮核查基线 `src/` 的 79 个源码文件（65 个 C#、14 个 XAML），并交叉检查测试、工程约束及发布文档。修改集中于字幕身份、课堂记录、翻译队列和工作台边界；没有读取真实课堂数据库、设置或凭据，也没有改数据库结构、依赖、框架、许可证或发布工作流。测试只使用合成句子与临时 SQLite。

## 根因与修复

1. **字符数切分会把持续增长的草稿提前变成定稿。** 生产链路关闭长草稿切分，另设 `CaptionRecordingPolicy`。实时区立即显示当前识别结果；课堂区只接收已解析身份的完整句。完整句有可信后继时立即收录，否则需持续观察到原文稳定 800ms。该时间不阻塞实时翻译，也不作为重复身份的判断依据。
2. **窗口从句子中部截断后，短后缀可能得到新身份。** 分段前使用上一个窗口、活动草稿及有界历史修订，按词边界恢复已知前缀。只在有位置证据的范围内复用身份；新短草稿的增长轨迹优先于历史匹配。
3. **同一活动草稿被大幅改写时，旧残片可能留到结束课堂。** 使用稳定窗口槽位和邻居识别强修订，沿用原 ID、Sequence 和 CapturedAt；已知历史回放不允许覆盖当前草稿。
4. **草稿翻译也能进入持久化路径。** 结构化草稿与流式片段现在只用于实时显示。课堂定稿原文先保存，译文再按 `(SessionId, SegmentId)` 更新；空译文仅在采集快照接口允许，普通手动编辑保持原校验。旧版本和同版本空占位不能覆盖新的成功译文。
5. **定稿晋升可能取消并重发同一个请求。** 同版本、同提供商和语言的请求原地晋升；复用进行中或刚完成的响应，保持队列位置。完成回调独立于可合并的视觉输出通道，避免已完成课堂译文因视觉更新被覆盖而消失。
6. **旧结果与课堂切换、结束操作交错。** 全链路携带课堂、采集轮次、原始时间和修订号。关闭入口后等待源落盘及队列收尾；显示和上下文更新再次校验作用域。退出异常或保存失败保留恢复标记。

固定实时区显示原文和当前译文；独立 Draft 标签不再显示。历史区域保留虚拟化、阅读位置、返回实时、字体设置和悬浮字幕。课堂结束时保留最后未完成的原文，不补造句号；当前界面会标记“未完句”。该标记未加入数据库，因此重新打开历史时不会恢复标记。

## 边界与验证

- 文本快照不包含真实发言事件 ID。没有新草稿轨迹、可靠右侧追加或邻居证据的孤立 `A → B → A` 仍存在不可判定性；保持有界待判定，不用时间到期强制创建身份。这会延迟或遗漏缺少证据的真实重复，不能承诺所有情况零重复且零漏句。
- 800ms 是课堂记录稳定性启发式，不证明语义完整；停顿更久后仍可能修订同一条课堂记录。没有标点的连续讲话一直留在实时区，结束课堂时保留未完句。
- 单活动槽位的大幅改写视为修订；若识别源完全不暴露边界，无法可靠区分它与一句全新未完成发言。
- 身份匹配账本有容量和时效限制；已收录课堂的修订授权元数据按课堂保留，避免慢翻译因匹配账本裁剪而被丢弃。
- 真正保留到结束才补存的早期未完句，在历史重新加载时仍可能按数据库插入顺序出现在后续完整句之后。运行中使用 Sequence；现有数据库只有秒级时间与插入 ID，无法恢复所有同秒句子的识别顺序。本轮不迁移数据格式，该边界尚未解决。
- 本轮执行环境为 Linux。可以运行跨平台逻辑和临时 SQLite 测试、交叉编译 WPF 及生成 Windows 产物；不能执行 Windows 桌面、UI Automation、Live Captions、DPAPI 或麦克风验收。具体结果见 `RELEASE.md`。

Windows 验收应在 `LECTURE_COPILOT_DATA_ROOT` 指向临时目录时执行：真实电脑声音和麦克风连续讲话、关闭及重建字幕窗口、网络慢响应、结束课堂再新建、历史浏览不跳动、放大字体与窗口缩放。确认重复来源消失、原文保存、迟到译文不串课，再扩大分发。
